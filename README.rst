Summary
*******

A standard library wrapper for prototype XC replacement features. Provided to allow easier
evaluaiton by current XC users.

********
Features
********

* Proposal for similar functonalty to XC interfaces/combine/distribute for C

************
Known issues
************

* Currently needs llvm tblgen tool to be installed and in PATH
